# Security

Do not post credentials, tokens, sensitive data, or vulnerability details in public issues, discussions, or pull requests.

To report a vulnerability, use **Security > Report a vulnerability** in the affected repository if private vulnerability reporting is enabled. Otherwise, contact the repository's maintainers through your organization's established private security reporting channel. If you do not know that channel, ask your organization's security team for the appropriate contact without sharing vulnerability details publicly.

Include the affected repository, a concise impact description, and reproduction steps in the private report. Do not include live credentials; arrange a secure way to share any sensitive evidence.
