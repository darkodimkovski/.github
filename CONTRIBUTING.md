# Contributing

Open an issue in the affected repository to discuss a problem or proposed change. Search existing issues first and include enough context to reproduce the problem without exposing credentials, personal data, or sensitive report data.

For changes to Power BI or Fabric solutions, open a pull request in the affected repository. Complete the deployment request template where it applies, describe the impact on data sources, refresh, access, and the semantic model, and link to non-sensitive validation evidence. Test in the appropriate development environment before requesting a production deployment.

Follow the review and deployment process established by the owning team. A pull request or a completed checklist does not by itself authorize a production deployment.
